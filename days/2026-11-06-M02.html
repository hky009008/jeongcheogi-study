M02 · 1과목 소프트웨어 개발 모의고사 2회 20문항 — 2023~2026 반복 출제 각도

2026-11-06 · A1~A9 모의고사 · 1과목

모의고사A1~A9 2020~2026년 필기 기출 20회차(2,000문항)를 모아 1과목 범위(A1~A9)의 출제 빈도를 센 뒤, 2023년 이후 반복해서 나온 출제 각도로 새로 쓴 20문항이에요. 2023년부터 나온 문제는 84%가 앞 회차에 이미 나왔던 문제라, 이 각도는 실제 시험에서 거의 같은 모양으로 다시 나올 가능성이 높아요. 기출 문장은 그대로 옮기지 않았고, M01에서 낸 개념은 다른 각도로만 다시 넣었어요.

실전처럼 푸는 법시간은 30분을 재 보세요. 과락 기준은 20문항 중 8문항, 평균 합격선은 12문항이에요. 계산 문제가 3개(11·15·20번) 있으니 연습장을 옆에 두세요. 다 고른 뒤 답안 복사로 붙여 넣어 주시면 채점하고 틀린 개념을 해설해 드릴게요.

문제 (채점 완료 · 10/20)

  1. 익스트림 프로그래밍(XP)이 내세우는 5가지 핵심 가치에 해당하지 않는 것은?
    정답·해설 (오답)고른 ④ → 정답 ②. D030-2(XP 가치) 이어 두 번째. 존중은 XP·스크럼 공통 가치예요(XP 2판에서 추가). XP 5가치 = 의사소통·단순성·피드백·용기·존중. 문서화는 가치가 아님(기출 오답 선지는 ‘정형 분석’).
  2. 자료 흐름도(DFD)의 구성 요소와 표기법의 연결로 옳은 것은?
    정답·해설처리 = 원(버블), 자료 흐름 = 화살표, 자료 저장소 = 평행선(이중선), 단말 = 사각형.
  3. 자료 사전(Data Dictionary)에서 “여러 항목 가운데 하나를 고른다(선택)”는 뜻을 나타내는 기호는?
    정답·해설[ ] 선택, { } 반복, ( ) 생략, + 연결, = 정의, * * 주석.
  4. UML 클래스 사이의 관계 중, 한 클래스가 다른 클래스를 메서드의 매개변수로 잠깐 사용해서 그 클래스의 명세가 바뀌면 영향을 받는 관계는?
    정답·해설의존 = 매개변수·지역변수로 잠깐 사용(점선 화살표). 연관 = 계속 참조, 일반화 = is-a, 실현 = 인터페이스 구현.
  5. 유스케이스 다이어그램에서 기본 유스케이스를 수행하다가 특정 조건을 만족할 때만 추가로 수행되는 유스케이스와의 관계는?
    정답·해설 (오답)고른 ③ → 정답 ②. 특정 조건일 때만 = 확장(extend). 항상 같이 실행 = 포함(include). 확장(extend) = 조건부 추가. 포함(include) = 항상 실행되는 공통 기능.
  6. 객체지향 분석 방법론 중, E-R 다이어그램으로 객체의 행위를 모델링하며 객체 식별 → 구조 식별 → 주제 정의 → 속성·관계 정의 → 서비스 정의 순서로 진행하는 것은?
    정답·해설 (오답)고른 ③ → 정답 ④. ‘E-R 다이어그램으로 행위 모델링’은 Coad-Yourdon만의 표지예요. 럼바우는 객체·동적·기능 3모델. Coad-Yourdon = E-R 다이어그램으로 행위 모델링. Booch = 미시·거시 개발 프로세스, Jacobson = 유스케이스 강조, Rumbaugh = 객체·동적·기능 모델링.
  7. HIPO(Hierarchy Input Process Output)에 대한 설명으로 옳지 않은 것은?
    정답·해설 (오답)고른 ④ → 정답 ①. HIPO는 하향식(Hierarchy = 위에서 아래로 쪼갬). ④는 HIPO의 실제 장점이에요. HIPO는 하향식 개발 문서화 도구. 가시적(도식 목차)·총체적(개요)·세부적 도표.
  8. 각 서브시스템이 입력 데이터를 받아 처리한 뒤 그 결과를 다음 서브시스템으로 넘기는 과정을 반복하는 아키텍처 패턴으로, 유닉스 셸의 | 연결이 대표적인 예인 것은?
    정답·해설 (오답)고른 ① → 정답 ③. D030 6번에서 맞힌 개념. “입력 받아 처리 → 다음으로 넘김”, 셸 | = 파이프-필터. 계층형은 위아래 계층이 서비스를 주고받는 구조. 파이프-필터. 계층형 = 계층별 서비스, MVC = 모델·뷰·컨트롤러 분리, 마스터-슬레이브 = 마스터가 작업 분배.
  9. 객체지향에서 정보 은닉과 가장 밀접한 관계가 있는 개념은?
    정답·해설캡슐화로 내부를 감추는 것이 정보 은닉.
  10. ‘자동차–엔진·바퀴’처럼 클래스 사이의 전체–부분(is-a-part-of) 관계를 나타내는 추상화 개념은?
    정답·해설 (오답)고른 ③ → 정답 ②. 전체–부분(part-whole) = 집단화. 분류화는 is-instance-of(객체–클래스). 집단화 = part-whole(is-a-part-of). 일반화 = is-a, 분류화 = is-instance-of, 연관화 = 독립 클래스 간 연결.
  11. 모듈 호출 관계가 A→B, A→C, B→D, B→E, C→E, C→F, E→G일 때 모듈 E의 팬인(Fan-In)과 팬아웃(Fan-Out)은?
    정답·해설 (오답)고른 ② → 정답 ①. 팬인 = 나를 부르는 모듈 수(B·C → 2), 팬아웃 = 내가 부르는 모듈 수(G → 1). 둘을 뒤집었어요. E를 호출하는 모듈 B·C → 팬인 2. E가 호출하는 G → 팬아웃 1.
  12. GoF 디자인 패턴 중 구조 패턴에 해당하지 않는 것은?
    정답·해설 (오답)고른 ② → 정답 ③. Proxy는 구조 패턴(대리자가 접근을 대신 제어). Strategy가 행위 패턴(알고리즘 교체). Strategy는 행위 패턴. 구조: Adapter·Bridge·Composite·Decorator·Facade·Flyweight·Proxy.
  13. EAI(Enterprise Application Integration)의 구축 유형에 해당하지 않는 것은?
    정답·해설EAI 유형 = Point-to-Point·Hub & Spoke·Message Bus·Hybrid. Tree는 없음.
  14. 소프트웨어 개발 방법론 테일러링(Tailoring)에서 고려하는 기준 중 내부 기준이 아닌 것은?
    정답·해설내부 기준 = 목표 환경·요구사항·프로젝트 규모·보유 기술(구성원 능력). 외부 기준 = 법적 제약사항·국제 표준 품질 기준.
  15. LOC 기법으로 예측한 총 라인 수가 48,000라인이고, 개발자 8명이 참여하며 1인당 평균 생산성이 월 300라인일 때 예상 개발 기간은?
    정답·해설48,000 ÷ (8명 × 300라인) = 20개월.
  16. CMMI(능력 성숙도 통합 모델)의 성숙도 단계에 해당하지 않는 것은?
    정답·해설초기 → 관리 → 정의 → 정량적 관리 → 최적화. ‘반복’은 없음(SPICE·CMM 혼동 함정).
  17. 소프트웨어 형상 관리 활동 중, 들어온 변경 요청을 검토·승인해서 기준선(베이스라인)에 반영하고 관리하는 활동은?
    정답·해설형상 통제. 절차 = 식별 → 통제 → 감사 → 기록(보고).
  18. 알파 테스트와 베타 테스트가 속하는 테스트 단계는?
    정답·해설 (오답)고른 ③ → 정답 ②. D030R 18번에서 맞힌 개념. 알파·베타는 사용자가 하는 인수 테스트. 시스템 테스트는 개발 조직이 전체 시스템을 검증하는 단계. 알파(개발자 장소, 사용자가 테스트)·베타(사용자 환경, 개발자 없이) = 인수 테스트.
  19. 테스트 오라클 중, 모든 테스트 입력값에 대해 기대 결과를 제공해서 발생한 모든 오류를 검출할 수 있는 것은?
    정답·해설참 오라클 = 모든 입력·모든 오류. 샘플링 = 일부 입력만, 휴리스틱 = 일부 + 나머지는 추정, 일관성 검사 = 변경 전후 결과 비교.
  20. 어떤 모듈의 제어 흐름 그래프에 노드가 8개, 간선이 11개 있을 때 McCabe의 순환 복잡도(Cyclomatic Complexity)는?
    정답·해설 (오답)고른 ② → 정답 ③. 11 − 8 + 2 = 5. ② 4는 +2 대신 +1을 쓴 값이에요. V(G) = 간선 − 노드 + 2 = 11 − 8 + 2 = 5.
